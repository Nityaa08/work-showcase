Terminal traps: green-on-black, matrix rain, typing on every visit, fake `visitor@portfolio$ help`, ASCII selfie,
macOS dots on every frame, invented commands, long transcripts.
Terminal rules: 6–12 true lines; type the command only, print output instantly; play once on view, hold final
frame + replay; honour prefers-reduced-motion; site colours; caption what to notice ("the red line is the bug").

## Case-study template (300–400 words)
1 header: title, one-line outcome, chips (role, weeks, stack, shipped) · 2 hero stage: one 8-second glimpse, red→green ·
3 problem: 2 sentences + 1 real redacted artifact · 4 beats FIND / FIX / PROVE, ≤40 words + 1 stage each ·
5 outcome tiles with named source · 6 "what I'd do next" + next case link. Footnote: data rebuilt, IDs redacted.
